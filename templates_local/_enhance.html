{# Makes clicks and form submits swap the page instead of reloading it. Nothing on the server changes: every route still returns the same redirect and the same HTML, and with JavaScript off every form still posts and reloads exactly as before. This only intercepts the navigation and puts the server's own markup in place, so there is still one source of truth for what a page looks like.
